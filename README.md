# rcpt-scanner

## Order Intake (`orders/`)

Paste a shop's order (email or WhatsApp), check the matched products, approve, then copy the compiled rows straight into the Google Sheet (columns A–K: shop number, shop name, then product/quantity pairs for round cakes, loaf cakes, cupcakes, brownies/blondies and cookies/biscuits).

Open `orders/index.html` (on GitHub Pages: `/rcpt-scanner/orders/`). Data is saved in the browser on each device.
